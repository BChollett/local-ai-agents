# Agent Tools Examples

This folder contains examples of custom tools that can be registered with the agent frameworks.

## Purpose

Show patterns for building reliable, well-scoped tools that agents can use effectively.

## Contents (to be expanded)

- Example tool definitions and schemas
- Input/output validation patterns
- Error handling and retry strategies
- Tool registration examples

Good tool design is often more impactful than model size for real-world agent performance.

See `docs/agent-orchestration.md` for how tools fit into the broader system.
